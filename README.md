# بازی اکو پینت — پروژه‌ی آماده‌ی اندروید (بدون نیاز به Secret)

دقیقاً مثل پروژه‌ی قبلی‌تان (هجوم): همه‌چیز از قبل توی خودِ ریپو آماده است — نه Capacitor، نه npm، نه هیچ GitHub Secret ای. فقط آپلود می‌کنید.

## راهنمای استفاده

1. یک ریپازیتوری جدید و **خالی** در گیت‌هاب بساز.
2. تمام محتوای این پوشه (همین فایل‌ها و پوشه‌ها، بدون پوشه‌ی اضافه‌ی بیرونی) رو داخل اون ریپو آپلود کن (Add file → Upload files، یا با git).
3. بعد از آپلود، برو به تبِ **Actions**. ورک‌فلوی «Build Signed APK» خودش با هر push اجرا می‌شود؛ اگر نشد، دستی از همان تب روی **Run workflow** بزن.
4. صبر کن (حدود ۳ تا ۶ دقیقه) تا بیلد سبز بشه.
5. دانلود از دو جا ممکن است:
   - تبِ **Actions** → روی اجرای موفق کلیک کن → پایینِ صفحه، بخشِ **Artifacts** → `echopaint-signed-apk`.
   - یا تبِ **Releases** (ورک‌فلو خودش هر بار یک Release جدید هم می‌سازد و APK را رویش می‌گذارد).

## چیزی که داخل این پروژه انجام شده

- بازی (`app/src/main/assets/index.html`) همان فایلِ شماست، با دو هوکِ اضافه‌شده: بعد از بردنِ هر مرحله و بعد از باختن (تمام‌شدنِ جوهر)، با احتمالِ ۳۵٪ به اندروید خبر می‌دهد که تبلیغِ میان‌صفحه‌ای نشان بدهد.
- کلیدِ اپِ تپسل (`nlhiaorm...`) و شناسه‌ی زونِ اینترستیشیال (`6aa439fccd33cd4ed6e43122`) که فرستادید، مستقیم توی `MainActivity.java` قرار گرفته.
- یک دکمه‌ی «⭐ حذف تبلیغات (VIP)» توی منوی بازی اضافه شده. خریدش فعلاً یک placeholder است (بلافاصله فعال می‌شود تا بتوانید کلِ جریان را تست کنید) — قبلِ انتشارِ واقعی در بازار باید به سیستمِ پرداختِ همان بازار وصل شود؛ همان‌طور که گفتید، آن موقع کمک‌تان می‌کنم.
- اپ کاملاً تمام‌صفحه (بدون نوار وضعیت/نویگیشن) اجرا می‌شود.
- آیکونِ خودتان (قلمِ آبی/طلایی) در همه‌ی سایزهای لازم (mdpi تا xxxhdpi، هم مربعی هم گِرد) ساخته و جایگزین شده.
- یک کیستورِ امضا (`app/keystore/release.keystore`) از قبل ساخته شده و توی `app/build.gradle` وصل شده، پس گیت‌هاب اکشن بدونِ هیچ تنظیمِ دستی یا Secret ای، مستقیم یک APK **امضاشده** تحویل می‌دهد.

## نکته‌ی مهم درباره‌ی امضا

این کیستور فقط برای همین پروژه ساخته شده (رمزها: `EchoPaint@2026Key!`، alias: `echopaintkey`). اگر بعداً خواستید نسخه‌ی جدیدی از بازی منتشر کنید (آپدیت)، حتماً باید با همین کیستور امضا شود وگرنه بازار آپدیت را قبول نمی‌کند. این ریپو (یا حداقلِ فایلِ `app/keystore/release.keystore`) را جایی امن نگه دارید.

## اگر SDK تپسل خطای بیلد داد

کدِ تپسل بر اساسِ نسخه‌ی رسمیِ `ir.tapsell.plus:tapsell-plus-sdk-android:2.3.2` نوشته شده (همان نسخه‌ای که در پروژه‌ی هجوم هم استفاده شده بود). اگر لاگِ گیت‌هاب اکشن خطای «cannot find symbol» برای یکی از کلاس‌های تپسل داد، فقط کافی‌ست `MainActivity.java` را برایم بفرستید تا با نسخه‌ی جدیدِ SDK هماهنگش کنم.
